========
启动契约
========

固件与交接
==========

同一 kernel.sys 包含 Multiboot2 BIOS 32 位入口与 EFI64 入口。
BIOS 入口检查 CPU 能力、建立页表与栈后进入共享 64 位内核。
解析交接数据时检查边界、对齐、长度和溢出；EFI 信息指针保留完整宽度。
固件、GRUB 与模块载荷需满足该协议，本仓不生成 ISO 或安装引导器。

根分区
======

设备发现后解析显式 ``root=PARTUUID=...``，匹配唯一 GPT 分区身份。
畸形、缺失或重复请求拒绝自动回退；连接顺序不能替代指定身份。
旧自动发现行为与显式选择是不同路线。内核映像和引导模块的内存范围
在物理内存管理初始化前保留，不能当作可重用空闲页。

日志
====

启动日志可镜像到 COM1。``logcolor=0`` 关闭内核颜色，``bootlog-pause=1``
在启动检查点等待输入；普通启动继续进入用户态。文字控制台采用现有
framebuffer 字形、pitch 和原生 RGB 转换，不假设紧密排列的 32 位像素。
