========
已知限制
========

平台
====

VMware 验证未完成；物理硬件未验证。QEMU 的成功只证明指定拓扑与用例。
部分 OVMF NVMe 高地址 BAR 超出现有 direct map 范围，设备可能无法初始化。
编译压力桌面交互、长期稳定性、完整本机自举及全部恢复路径未完成整版验收。
GPU 支持限于已实现的设备与能力，不等于通用 Linux DRM 驱动兼容。

接口与测试
==========

驱动 API golden 为 168 字节、实际结构为 296 字节的既有差异仍保留。
不重生成 golden 或修改音频支持清单掩盖失败。部分旧 fixture 与总测试存在
独立失败，定向测试通过不能称为完整 ABI 或 POSIX 认证。
CPU 统计精度仍为 10 ms，未完整拆分全部用户/内核/子进程统计。
