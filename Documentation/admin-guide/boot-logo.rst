====================
Framebuffer 启动徽标
====================

显示与移除
==========

索引颜色图像直接嵌入内核只读数据，无需文件系统或用户态加载。
按发现的逻辑 CPU 数量绘制图标，适当留距，屏幕不足时换行或缩放，同时保留
文本行。该数量不是 CPU 插槽数。用户态启动前移除徽标，恢复完整控制台。
绘制遵守 framebuffer pitch、原生颜色与边界；不能因图像更换覆盖屏外内存。

验证
====

make test-boot-logo 使用实际绘制器检查 RAM surface；QEMU 的数量、留距、
持续显示和自动隐藏要由真实启动画面检查。VMware 验证未完成，不能从 QEMU
设备模拟推导真实 VMware 或物理硬件显示成功。
