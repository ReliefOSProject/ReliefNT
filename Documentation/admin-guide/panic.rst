===============
文字 Panic 诊断
===============

输出行为
========

文本 VT 保留编号并从当前位置继续输出；GUI 从屏幕左上角绘制文字。
只有文字及空格占用的字符格覆盖黑底，其余 framebuffer 像素保持原样。
GUI 到达底部停止可见绘制，不滚动原桌面；完整诊断继续进入串口和 VT 历史。
红色标题、黄色解释及白色寄存器提高可读性，控制字符受限并转义。

诊断包括异常与错误码、RIP/RSP/RFLAGS、段/控制寄存器、页错误解释、可用的
通用寄存器、CPU/APIC、其他 CPU 停机数量、任务/PID、内核版本与构建身份。
入口未保存的值明确标为不可用，不把过期 CR2 解释成非页错误的故障地址。

紧急路径
========

关闭本地中断，向其他在线 CPU 发送 NMI，并有界等待；绕过普通控制台、
驱动和显卡锁及动态分配。设备或内存损坏时只能尽力输出，保留串口证据。
不自动重启，也不无界遍历可能损坏的栈链。用同一构建调试符号解析指令地址。
用户态异常按其信号/调度策略处理，不把所有用户错误提升为内核 panic。
