=================
ReliefNT 内核文档
=================

ReliefNT 是 ReliefOS 的独立 x86_64 内核。
本手册说明启动、源码部件、公开接口和验证边界；不包含用户态应用或镜像安装器。
Linux ABI 是已实现接口的兼容目标，不代表完整标准认证。
