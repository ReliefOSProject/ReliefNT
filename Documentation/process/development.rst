============
内核开发约定
============

模块与注释
==========

先阅读 AGENT.md、相关模块与构建图。每个生产文件独立编译，由本地 Kbuild
登记，不包含 .c/.inc 实现代替拆分，不恢复全局源列表。
模块内共享状态只定义一次，跨文件可见不意味着对用户公开；锁、IRQ 状态、
所有权和生命周期必须在接口中表达。

保留现有 Doxygen 函数注释约定，说明职责、参数、可空性、所有权、容量与
返回错误；不要为文档重组批量改写算法或函数签名。

范围与提交
==========

不修改导入的 Linux Kbuild/Kconfig 引擎来规避测试。源迁移映射位于
configs/kernel-source-map.json，仅供审计，不参与生产编译。
新 UAPI 需要导出白名单和用户态联动；普通重构保持磁盘格式和行为。
只有用户明确授权才提交/推送，先推本仓，再由父仓更新 gitlink。
