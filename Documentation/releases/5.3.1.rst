==============
ReliefNT 5.3.1
==============

更新内容
========

- 新增 Linux inotify 文件事件接口：实现 inode 监听、按用户配额、完整事件记录、重命名 cookie、队列溢出恢复和可写 sysctl；支持共享打开文件描述、poll/epoll、权限检查及监听对象的删除、卸载生命周期，导出对应 Linux UAPI。

- 改进高负载调度与执行路径：合并远端重新调度 IPI，使用各 CPU 本地 LAPIC 抢占和 ACPI PM 公平时间计数，减少延迟 PIT 中断导致的运行时间漏计；无 I/O 私有缺页保留完整用户返回检查，文件 I/O 在原有安全边界按工作预算让出。

- 修正同属主 PRIO_PROCESS 优先级调整权限和 evdev 事件代际处理，使桌面优先级策略、重复输入和等待唤醒符合现行接口语义；不新增实时调度或整个 syscall 的硬实时保证。

- 优化 SVGA 软件扫描输出：减少分散损伤区域的重复上传，使用适合显存的像素复制，并为经过校验的 SVGA 像素窗口配置 PAT write-combining；设备控制寄存器、FIFO、fence、VT 与 DMA 所有权边界保持受控。

- 新增 xHCI USB2/USB3 Hub、多级路由与下游设备热插拔：支持 Hub 端口供电、复位、状态变更和过流处理，USB2 multi-TT Hub 使用 single-TT 模式；TT 控制传输、子树移除及控制器模块卸载保留真实设备和在途资源生命周期。

- 新增 VFS 正/负名称缓存：只缓存成功与 ENOENT，按已审计文件系统的变更代际和设备写入代际校验；直接块写入同时失效原生文件系统缓存，设备撤销后恢复实时查询，权限仍逐次检查。缓存采用 512 KiB 分配载荷预算及 LRU，不固定 inode、挂载或模块引用；有界回收不会饿死文件页与 swap 回收。

- 补充 inotify、调度、PAT、xHCI Hub 和名称缓存的原生探针、宿主回归与文档；修复独立版本检查遗漏 VFS 缓存链接对象的问题，以及缓存文档的标题格式。

破坏性更新
==========

- **是，仅涉及内核内部 ABI 和模块配套。** 内部 VFS、文件系统与块设备接口有扩展，旧 .ko 和 prepared SDK 必须随新内核重新构建；不改变已有用户态 syscall 编号或磁盘文件系统格式。新增 inotify 是 Linux 接口扩展，不属于 POSIX 接口。

更新与迁移注意事项
==================

- 本次为**正式源码 Release**，只提供标签及 GitHub 自动源码归档，不附预编译内核、模块或 SDK。使用 v5.3.1 和锁定依赖重新构建；内核、initramfs、模块、符号及 ABI 清单必须配套更新。

- 旧配置执行 olddefconfig 后核对 y/m/n；defconfig 默认仍将生产部件内置。树外模块需使用本版本对应的 Module.symvers 和 prepared SDK，不忽略 vermagic 或类型 CRC 校验。

- inotify 目录监听不递归；收到 IN_Q_OVERFLOW 必须重新扫描。动态文件系统和未明确声明代际能力的提供者继续实时查询，名称缓存不会代替授权或改变文件句柄身份。

- xHCI Hub 的 BOT 存储和 boot HID 延续既有设备范围，不包含 UAS、通用 HID 报告解释器、USB 音视频等时传输、USB4 或 Type-C/PD。真实 HS/SS Hub、物理 USB 设备和 10/20 Gb/s 链路尚未完成硬件验证。

- 既有功能验证覆盖 QEMU 中的 ext4/tmpfs inotify、编译负载桌面交互、两级 Hub 键鼠和存储、热移除及模块生命周期。名称查询微基准在相同用户态、2 vCPU、1024 MiB 的 QEMU/KVM 下，ext4 现有/缺失名称吞吐约为对照的 1.55/1.67 倍；不代表整体编译提速或其他平台性能承诺。

- 本次发行检查版本生成、5/3/1 数字宏、后缀处理、procfs 夹具和严格文档构建；没有为本标签重建内核/镜像或重跑全部运行测试。历史单项结果不等于整版复验。**VMware 验证未完成**，物理硬件和长期稳定性未完成验收。

- 扩展 rootfs 宿主套件仍有一项既有 UTS 夹具编译错误：rootfs_uts_test.c 引用了已移除的 linux_uts_load_hostname。该夹具未在本次发行中修改；不将此项算作通过。

开发者提示
==========

- 基础版本为 **5.3.1**，生成数字字段为 **5/3/1**；EXTRAVERSION、LOCALVERSION 和模块 ABI 身份后缀独立生成，完整 release 继续遵守 31 字节限制。

- 新文件事件头通过正式 headers_install 导出，内部名称缓存与块设备代际接口不成为稳定用户态 ABI。按各目录 Kbuild 构建；内核实现、测试与手册继续由本仓持有。

- 原始 ABI golden 未重生成。定向回归与接口对照不表示完整 Linux/POSIX 认证；调度优先级、软件上传和文件缓存优化也不表示已经完成 VMware 图形或硬实时验收。

- 更新范围为 5.3.0 版本提交 **3082fb4656d65f99b1d5edab249913276e25bc3e** 之后至本次版本提交；仅记录本仓最终有效更新，不包含 ReliefOS 应用、桌面和镜像打包。下一版以本次版本提交为起点。
