==============
ReliefNT 5.3.3
==============

更新内容
========

- 新增 Realtek RTL8111/8168 千兆和 RTL8125 2.5GbE PCIe 网卡驱动，各设备独立维护资源和网络接口，并提供内置及 ``r8169.ko`` 配置。实际支持范围取决于芯片版本，见 Realtek 驱动手册。

- 新增 VMXNET3 驱动，支持 PCI ``15ad:07b0``、revision 1 和 UPT 1，可内置或构建为 ``vmxnet3.ko``。每个设备独立运行一对发送、接收队列，使用 1500 字节 MTU、软件校验和与轮询完成。

- 网络栈支持多个独立接口，将地址、路由、ARP、IPv6 邻居发现及传输路径接入相应设备，减少多网卡状态互相覆盖的问题。

- 新增 ext3 文件系统前端、``ext3.ko`` 和原生格式化器，复用 ext 引擎处理经典块映射、内部 JBD 日志及 ordered 数据模式。补齐文件系统探测、挂载、重挂载、日志恢复与模块所有权。

- 块设备导出可移动卷身份，FAT 支持挂载权限选项，为用户态挂载和安全弹出提供基础。procfs 文件描述符枚举保留匿名描述符，避免目录遍历遗漏仍打开的资源。

- 控制台补齐 ncurses 输入和虚拟终端状态处理，修复 Shell 通过退格及方向键移动光标时文字被意外擦除的问题。

- 内核手册增加英文和日文版本；移除已退役的内核诊断模式、独立载荷、私有控制 ABI 及构建清单，保留普通符号文件和 debug profile。

破坏性更新
==========

- **是，涉及私有诊断 ABI、构建产物和内核模块配套。** 不再提供 ``kerneldebug.sys`` 和旧诊断控制接口；依赖这些接口的工具或安装清单需要迁移。内核内部接口并非稳定的 Linux 二进制模块 ABI，旧 ``.ko``、``Module.symvers`` 和 prepared SDK 必须随本版重建。没有改变既有标准 syscall 编号，也不要求转换现有磁盘格式。

更新与迁移注意事项
==================

- 本次为**源码 Release**，只提供标签和 GitHub 自动源码归档，不附预编译内核、模块、SDK 或镜像。对现有配置执行 ``olddefconfig``，并使用同一版本的内核、模块和 initramfs；默认配置仍将生产驱动内置。

- VMXNET3 当前不启用硬件校验和、分段、VLAN 剥离、RSS 或 LRO；QEMU 的设备模型和宿主驱动模型验证不代表 VMware 平台验收。Realtek 不承诺覆盖全部同名芯片版本，实体网卡仍需按具体设备验证。

- ext3 支持内部日志和 ``data=ordered``，不提供外部日志或任意 ext4 扩展的兼容承诺。原生格式化器使用 128 字节 inode，时间戳受 2038 年边界限制；格式化会破坏目标数据，使用前须备份。

- 发行定向检查覆盖版本生成、基础与附加版本字符串、数字宏、无操作重生成和 procfs 回归，以及中英日文档。本次未重新编译完整内核、打包或执行 QEMU 整版回归；**VMware 验证未完成**，实体硬件和长期稳定性尚未完成本版验收。

开发者提示
==========

- ``configs/build-version`` 为 **5.3.3**，生成数字字段为 **5/3/3**；EXTRAVERSION、LOCALVERSION 和模块 ABI 后缀仍独立处理，并遵守完整 release 字符串长度限制。

- 驱动、文件系统、UAPI、内核测试及对应手册归本仓；ReliefOS 的安装器、应用、打包和系统集成独立发布。保留 ABI golden 与音频策略，不以修改基线掩盖失败。

- 本次范围为上一版本提交 **1dfd1eb8541bb31e51836aab40827694eb82fed2** 之后至本次 5.3.3 版本提交；仅汇总内核仓最终生效内容，排除 ReliefOS 应用、打包与纯合并。下一版以本次版本提交为起点。
