==============
ReliefNT 5.3.2
==============

更新内容
========

- 新增原生 PCIe ``e1000e`` 网卡驱动，支持 Intel 82574L/82574IT 与 82583V，并由现有网络服务统一管理设备。

- 新增可调度内核线程与工作队列，支持并行、合并及延迟工作；改进常驻管道 I/O 并行度和 FIFO 打开路由。

- 按 CPU 缓存物理地址位宽，减少重复读取和同步；写保护缺页在并发 COW 处理已完成时重新检查并继续，而不是误报故障。

- 修复 netlink multipart dump 的完成报文边界，并使 ``ppoll`` 支持调用期间的临时 signal mask。

- 实现 ``RLIMIT_FSIZE`` 对文件写入的限制，并扩展 mount/bind 实例支持，为多个系统实例隔离挂载关系。

- 移除已退役产品激活身份辅助接口，并修正 GNU Unifont 构建下载来源。

破坏性更新
==========

- **是，涉及内核内部 ABI、模块配套和一项已退役的私有接口。** 内核、initramfs、树外模块、符号版本及 ABI 清单必须使用同一版本；旧 ``.ko`` 和 prepared SDK 不能与本版混用。移除的产品激活身份 helper 不再提供，依赖它的程序须改用标准系统信息接口。没有改变既有 syscall 编号或磁盘文件系统格式。

更新与迁移注意事项
==================

- 本次为**源码 Release**，只提供标签和 GitHub 自动源码归档，不附预编译内核、模块、SDK 或镜像。使用 v5.3.2 对应配置执行 ``olddefconfig``，并重新构建完整内核与 initramfs；树外模块须使用本版 ``Module.symvers`` 和 prepared SDK。

- ``e1000e`` 的设备表仅覆盖 Intel 82574L/82574IT 与 82583V。验证范围包括 QEMU 对 82574L 的模拟和 82583V host model；不应据此推断其他同属 e1000e 家族的设备或实体网卡已验证。

- 新增 mount/bind 实例能力扩展挂载关系的隔离语义；更新时应使用匹配的用户态、内核和启动配置。``RLIMIT_FSIZE`` 对超出限制的写入返回文件大小错误，应用应检查短写及 ``EFBIG``。

- 本版验证包含版本生成、字符串与数字宏、工具和 ownership 检查，以及 14 个 host smoke suites。该检查不等于完整系统启动、QEMU 全量回归或运行时驱动验收；VMware、实体硬件和长期稳定性尚未完成验收。

开发者提示
==========

- ``configs/build-version`` 为 **5.3.2**，生成的版本数字字段为 **5/3/2**；EXTRAVERSION、LOCALVERSION 和模块 ABI 后缀仍分别处理，并遵守完整 release 长度限制。

- 内核实现、UAPI、模块接口、探针和手册归属本仓；ReliefOS 桌面、打包、RPR 与镜像流程归主仓。保留既有 ABI golden，不以重生成基线掩盖差异。

- 本次范围为 ReliefNT v5.3.1 提交 **d4e365ba2672c25cf33f8c3a7e3bcecfe62ee9c2** 之后至 v5.3.2 标签指向的版本提交；仅汇总本仓最终生效内容，排除 ReliefOS 应用、打包及纯合并。下一版以该版本提交为起点。
