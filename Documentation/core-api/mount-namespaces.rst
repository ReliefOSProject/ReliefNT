================
挂载命名空间快照
================

``vfs_namespace_snapshot()`` 在独占 VFS 执行权下，将活动挂载树复制到地址固定、
由调用方管理的空命名空间中。它保留覆盖层、不可绑定挂载和图内传播关系；新旧
命名空间之间不会建立传播关系。各副本直接持有原生文件系统后端，共享目录项和
文件内容，但挂载策略和写入者计数独立。挂载 ID 从 VFS 全局序列分配，传播组号
仍仅在各自的命名空间内有意义。

可选的 root 和 cwd 引用按原挂载对象和目录项重新绑定，而不是重新查找路径；
即使路径已被其他挂载覆盖，所指目录项也不变。已摘除的路径保持原样，其他活动
命名空间的路径返回 ``EXDEV``。所有分配完成后才发布新树并替换路径；失败时
不改变原树、目标、路径或 ID 游标。

最后一个图使用者离开时，``vfs_namespace_retire()`` 摘除整棵树而不传播卸载。
已持有的路径继续有效，后端由现有的延迟清理队列处理。与之不同，严格的
``vfs_namespace_destroy()`` 在仍有外部引用时拒绝销毁。此接口用于内核内部；
当前没有向用户态开放挂载命名空间创建或切换。
